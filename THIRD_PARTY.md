# Third-party code

Bundled in `third_party/`:

- **SQLite 3.54.1** (amalgamation), public domain. Used only as an in-memory database.
- **stb_image v2.30** (commit `4e9b368`), public domain or MIT. Decodes PNG icons.

Linked from the VitaSDK: vita2d, FreeType, libpng, libjpeg and zlib (see the VitaSDK licenses).
